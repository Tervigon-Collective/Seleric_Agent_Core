## 4. Enhancements v2 did not have

- **Date axis as a parameter** with an always-visible Undated member (52 orders / ₹81,680 on brand 20): D-28..D-37.
- **One ledger** that every view reconciles to (gold -> v3 proven with 0 unexplained ₹ by `v3_reconcile_gold.py`).
- **Evidence codes** on every order outcome and `cost_method` / `cost_status` on every cost row.
- **Google ad group / ad / device / network** drill (v2 stopped at campaign).
- **Monthly close** and `maturing` flag for cohorts under 45 days.
- **41 new metric ids**: `channel_cancelled_orders`, `channel_returned_or_cancelled_orders`, `channel_rto_orders`, `channel_unknown_orders`, `checkout_fee`, `cod_handling_fee`, `exchange_cost`, `exchange_credit_amount`, `exchange_price_adjustment`, `exchange_refund_count`, `new_customer_net_sales`, `order_pnl_return_cancel_revenue`, `order_pnl_rto_revenue`, `platform_reported_landing_page_views`, `product_attributed_contribution`, `product_attributed_net_sales`, `product_attributed_revenue`, `product_cogs_credit`, `product_order_cancelled_orders`, `product_order_checkout_fee`, `product_order_cod_handling_fee`, `product_order_exchange_cost`, `product_order_exchange_price_adjustment`, `product_order_product_cogs_credit`, `product_order_provisional_ops_cost`, `product_order_return_cancel_revenue`, `product_order_returned_or_cancelled_orders`, `product_order_rto_revenue`, `product_order_shipping_revenue`, `product_order_shipping_revenue_reversal`, `product_order_weight_discrepancy_cost`, `product_rto_orders`, `provisional_ops_cost`, `rto_orders`, `rto_revenue`, `shipping_revenue`, `shipping_revenue_reversal`, `transactions`, `units_cancelled`, `units_rto`, `weight_discrepancy_cost`.
